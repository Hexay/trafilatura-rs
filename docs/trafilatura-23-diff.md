# trafilatura 2.2.0 → 2.3.1: semantic diff of the extract() path

Scope as in [trafilatura-2x-diff.md](trafilatura-2x-diff.md): `extract(html, output_format="txt")` with the parity
configs of tools/env.sh, with and without comments. "same" = pure refactor.
The Rust port (`crates/trafilatura-rs/src/trafilatura2`) now tracks 2.3.1 only; 2.2.0 is no longer reproduced.

Environment: 2.3.1 requires lxml>=6.1.3, htmldate>=1.11.0, justext>=3.0.2, charset_normalizer>=3.5.2,
urllib3>=2.8.0; references use lxml 6.1.3 (libxml2 2.14.6), jusText 3.0.2, Python 3.13 (`.venv-t23`). The jusText
stoplist union is unchanged.

## API (core.py)
- `extract()` gains `fast` as 4th positional parameter, before the deprecated `no_fallback` (both → fast mode,
  `no_fallback` warns DeprecationWarning). `include_formatting` defaults to None (markdown implies formatting).
  `deduplicate` accepts an `LRUCache` as a scoped cache. `max_tree_size` set → ValueError. The body is
  `_internal_extraction(**locals())`.
- Output: `normalize_unicode((xmltotxt(body) + "\n" + xmltotxt(comments)).strip())`, comments body empty → same.

## Cascade (core.trafilatura_sequence)
- Raw-tree prunes now in place and inherited by every stage (readability, jusText, baseline, html2txt):
  **new** RAW_TREE_PRUNE_XPATH always, then (comments off, precision or not a forum) **new**
  REMOVE_COMMENTS_AND_LISTS_XPATH (was a copy pruned with REMOVE_COMMENTS_XPATH).
- Precision post-conversion prune with REMOVE_COMMENTS_XPATH: same place.
- Stages 1-2 factored as `_extract_and_compare`; results are `(body, text)`, lengths are `len(text)`.
- Baseline rescue accepted **only if it adds text** (`b_len > len(temp_text)`).
- Escalation input: the (already pruned) tree itself when comments are off; recall retry =
  `_extract_and_compare(*_prepare_tree(tree))`, jusText candidate on `copy(tree)`. Gates and ratios same.
- `MIN_EXTRACTED_COMM_SIZE` removed; `bare_extraction` rejects only when text < min_output_size **and** comments <
  min_output_comm_size.

## Comments (include_comments=True)
- `extract_comments` strips only ref and span (no longer a), uses TAG_CATALOG and `handle_textnode(comments_fix=True)`,
  clears the copied node's attributes, appends node by node, and removes the source subtree with
  `delete_element(keep_tail=False)` only when the comments body is non-empty. COMMENTS_XPATH/DISCARD: whitespace only.
- Thread forum (JSON-LD DiscussionForumPosting) with captured comments: they are the posts. The comments body is
  emptied, `cleaned` is rebuilt as `convert_tags(copy(backup))`, and the captured posts are kept aside.
  Posts missing from the final body are appended (salvage) unless the baseline or an escalation candidate was accepted.
- Escalation input with comments on (not a forum): a copy pruned with REMOVE_COMMENTS_AND_LISTS_XPATH if comments
  were captured, else REMOVE_COMMENTS_XPATH.

## settings.py / settings.cfg
- MANUALLY_CLEANED **− ins**; MANUALLY_STRIPPED **+ wbr**; TAG_CATALOG **− blockquote, pre** (now code, del, head,
  hi, lb, list, p, quote). settings.cfg adds network-only keys (SSRF_PROTECTION, INSECURE_SSL_FALLBACK).

## xpaths.py
- REMOVE_COMMENTS_XPATH: ids `^(?:[Cc]omment(?!ary)|comol|disqus_thread|dsq-comments)`, classes
  `^[Cc]omment(?!ary)|(?:article|post)-comments` (lookahead: Python `re`; port routes lookaround patterns to
  fancy-regex in `py/re.rs`).
- **New** REMOVE_COMMENTS_AND_LISTS_XPATH (adds ol/ul comment lists, disqus ids excluded) and RAW_TREE_PRUNE_XPATH
  (mvp-post-add / infinite-scroll containers not holding the h1, elementor share buttons).
- OVERALL_DISCARD_XPATH: + id `^ad-`, classes `(?:^| )ad-`, `dfp[Aa]d`, `more-on`.
- PRECISION_DISCARD_XPATH: `bottom` only as a token edge (`(^|\s)bottom|bottom(\s|$)`).
Port: regenerated by `harness/gen_xpaths2.py`.

## utils.py
- `repair_faulty_html`: checks only the first 4 lines of the first 4096 code points.
- `image_src` replaces `is_image_element` (data-src, src, then any data-src* holding an image file); serializer
  list/cell helpers removed.
- Decompression caps, `detect_encoding`/`decode_file` fast path: bytes input only (str path unaffected).

## htmlprocessing.py
- `tree_cleaning`: **MathML recovered** (`recover_math`: annotation[@encoding="application/x-tex"] else @alttext,
  as `\(..\)` / `\[..\]` for display=block, written into the tail before `math` is deleted). **Forms** no longer in
  the cleaning list: after deletions a form holding more than half the page text becomes a div, others are deleted.
  figure-with-table and presentation tables → div in one `iter("figure", "table")` loop.
- `prune_html`: CUT_EMPTY_ELEMS collected first via `iterdescendants` (root excluded), `text is None` test.
- `prune_unwanted_nodes(with_backup)`: matches of all expressions collected on the unpruned tree, outermost only
  deleted, and only if more than 1/7 of the text survives (no tree copy).
- `link_density_test(element, favor_precision)`: computes the text itself, returns `(boilerplate, short_with_links)`;
  link-farm branch skips paragraph listings (every link alone in a `p`). `delete_by_link_density` backtracks on
  `short_with_links`. `handle_textnode`: empty separator elements kept unless comments_fix; graphic via `image_src`.
  `process_node`: tail → text only for childless elements.
- `convert_tags`: link/heading/quote conversions same (links off).

## main_extractor.py
- `handle_titles` copies headings with children (minus "done"), marks the source descendants done.
- `handle_formatting`: parent check only (no previous-sibling fallback).
- **New** `process_nested_elements`/`_append_block` used by lists and quotes: nested lists, p with children and
  graphics become blocks (tail kept as text if the block is dropped), inline-carried elements keep their children,
  others move their tail into the last child.
- `handle_lists`: skips items already done by a nested call, joins `text`/`tail`, keeps items with text or a graphic.
- `handle_paragraphs`: strips unexpected descendant tags first, INLINE_CONSUMING handling, `_copy_attrs`.
- `handle_table`: rewritten (direct-child rows, orphan cells, captions as header rows, nested tables left to the
  main loop, `_fill_cell`).
- `handle_textelem`: INLINE_CONSUMING → `handle_formatting` (span no longer handled; stripped at the end of
  `prune_unwanted_sections`, with ref when links are off). `handle_other_elements`: only div, and only when divs
  are potential tags.
- `_extract`: single-text-run frame rule, frame lead paragraph, elements already moved into the body skipped,
  tails of rebuilt blocks (code, quote, list, table) kept as paragraphs.
- `recover_wild_text`: skips consumed/handled elements, image-only and fragment dedup.
- `extract_content`: whitespace-only `lb` tails cleared outside code/pre.

## external.py / readability_lxml.py
- `try_readability`: no retry length. `compare_extraction(cleaned, raw, body, text, options)`: jusText accepted on
  an unclean body only if not much shorter and (longer, or images off, or no graphic); on a short one only if
  longer; adopting jusText cancels readability. `_prefer_readability` h2-h4 test via `iter` (root included).
- `sanitize_tree`: graphics rebuilt by `handle_image` or deleted; span (and a when links off) stripped first.
- readability fork: one pass (no ruthless retry); unlikely-candidate regexes case-sensitive on lowercased
  class/id (+ `content` in okMaybe, body/html skipped); div → p when no descendant tag starts with a block prefix
  and (no link or loose text); conditional cleaning over the article subtree only, counts via `iterdescendants`,
  empty elements kept iff the nearest non-empty siblings sum over 1000 chars. Port: `readability/v23.rs`.

## baseline.py
- `block_text` (text_content with block boundaries spaced) for articles, paragraphs and JSON markup; paragraphs
  nested in another scraped tag skipped. `html2txt` shares `_spaced_text`.

## xml.py (txt)
- Serializer rewritten: list markers per item with nesting indent (`_item_needs_marker`, `_list_marker`), tails
  (`_append_tail`), cell escaping, separators (`_append_spaced`), surviving `ref`s rendered as `[text](target)`.
  Markdown output changed too (not ported; include_formatting falls back to Python).

## deduplication.py
- `LRUCache` gains `increment()`; `duplicate_test` semantics same (optional scoped cache) → reused.
